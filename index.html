Recurring Total & One Time Total only · No extra charge columns · No level labels

What changed from the previous version Root/bundle rows now show two lines in the amount cells when own charges exist: the grey aggregate total on top, and the blue own charge / strikethrough original below — clicking the blue value opens the own charge waterfall for that column. If a root or bundle has no own charge for a column, that cell shows only the grey aggregate (no blue line). The ⓘ icon on column headers explains what each column means — no ⓘ needed in the data cells. Child leaf rows keep the existing blue + strikethrough on the cell itself.

Blue own charge / strikethrough visibility rule: Show the blue value + strikethrough only when this specific product has ITS OWN adjusted charge for that column. A product with no own adjusted charge in a column → show only the grey aggregate total (no blue line). See Scenario F for a pure container (no blue lines in either column).

Column header ⓘ icons (Recurring Total / One Time Total): Both column headers carry a subtle ⓘ that on hover explains their dual meaning: aggregate sum on parent/bundle rows, direct charge on leaf rows. This resolves the ambiguity without renaming the columns or adding extra columns.
Pure container — root has no own charges Business Cloud Suite is a container product: it groups child products together but carries no own charges itself. The root row shows a grey aggregate total only — no blue own charge line, because there is no own adjusted charge to show. Compare with Scenarios A–C where the root/bundle DID have own charges and the blue own charge value appears below the aggregate.
